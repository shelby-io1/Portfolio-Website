# Shahid Zahoor Khan — Portfolio

A personal portfolio website built with **React + Vite**, styled with **Tailwind CSS v4**, and animated with **Framer Motion**.

## Sections

- **Hero** — Animated gradient name, shooting stars background, scroll indicator
- **Marquee Cards** — Dual-row scroll-driven carousel showing skills/service cards and stat cards
- **About** — Word-split animated text reveal with bio
- **Services** — White rounded container with glowing shadow, service rows with numbers
- **Projects** — Sticky stacking cards with parallax scroll, color identity blocks, clickable tiles linking to GitHub
- **Contact** — Email/phone pills, Instagram & LinkedIn links, footer copyright

## Tech Stack

| Tool | Purpose |
|------|---------|
| Vite | Build tool & dev server |
| React | UI framework |
| Framer Motion | Scroll / entrance animations |
| Tailwind CSS v4 | Utility-first styling |
| Google Fonts (Kanit) | Typeface |

## Getting Started

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`.

## Build

```bash
npm run build
```

Output goes to `dist/`.

## Deployment

Recommended free hosts: **Vercel**, **Netlify**, or **Cloudflare Pages**.

Connect your Git repo or drag-drop the `dist` folder.
